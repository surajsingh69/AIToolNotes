# AIToolNotes GitHub Repo
**Purpose:** Drive genuine traffic to https://aitoolnotes.blogspot.com/ via GitHub search, Google indexing, and community sharing.

---

## Traffic Strategy

1. **GitHub Search/Explore** - Repo appears in search results for "free AI tools"
2. **Google Indexing** - GitHub Pages gets indexed, ranks for long-tail keywords
3. **Community Sharing** - Useful enough to share on Reddit, Discord, Twitter
4. **Backlinks** - GitHub is high-authority domain (DR 96)

---

## Repository Structure

```
aitoolnotes/
├── README.md                    # Main curated list with links
├── tools/
│   ├── video-generators.md      # Free AI video tools
│   ├── voice-generators.md      # Free AI voice tools
│   ├── content-creators.md      # Free tools for creators
│   └── students.md              # Free AI study tools
├── scripts/
│   └── ai_tool_finder.py        # Simple CLI tool

```

---

## Content Strategy

Each tools page includes:
- 5-10 tools with brief descriptions
- Link to AIToolNotes for detailed review
- "Want to learn more?" call-to-action

No affiliate links, no spam, genuinely useful.
